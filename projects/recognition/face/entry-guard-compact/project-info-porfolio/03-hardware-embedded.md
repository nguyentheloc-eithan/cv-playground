# Hardware and embedded design

Status: **designed, documented, enclosure generated; not assembled; no firmware yet.** Spec: SOL-HW-001 v0.1 (23 Nov 2026), requirements HW-001 to HW-011. Built from ready-made boards (no custom PCB) to reach a pilot in about 10 weeks.

## Block diagram
```
Solar panel 6V 1.5W -> CN3791 charger (+NTC temp cutoff) -> 18650 protected cell
Cell -> main board (ESP32-S3 + LTE Cat-1) -> OV2640 camera
PIR AM312, accelerometer (ADXL345/LIS3DH), compass QMC5883L, reed switch -> wake-capable GPIOs
Board -> MOSFET -> 1W white LED;  Cell -> divider -> ADC (battery %)
Board -> LTE antenna / SIM
```
See `diagrams/power-chain.mmd`.

## Parts and why
| Part | Choice | Why |
|---|---|---|
| Main board | ESP32-S3 + LTE Cat-1 (LilyGO T-SIM7670G-S3 class) | Wi-Fi, 4G, camera connector, deep sleep in one board |
| Camera | OV2640, 66° fixed focus, sun hood | cheap, 2 MP, fits connector (OV5640 as upgrade) |
| Motion | AM312 PIR (~12 µA) | far lower power than HC-SR501 |
| Tilt/knock | ADXL345 or LIS3DH | micro-amp operation with interrupt that wakes the board (MPU6050 rejected: milliamps) |
| Heading | QMC5883L compass | sees a left-right turn a tilt sensor cannot; only **change from baseline** is used because metal gates distort absolute heading |
| Cover | glass reed switch + 6×3 mm neodymium magnet | zero power, wakes board, detects cover leaving the back plate |
| Charger | CN3791 (6 V in) | panel-aware (MPPT-like) single-cell charge |
| Cell | 18650 3000 mAh protected (~11 Wh) | common; LiFePO4 considered (cooler, needs other charger) |
| Light | 1 W warm-white LED via logic-level MOSFET | good face colour; **infrared rejected** because it hurts recognition |

## Power budget (ESTIMATE, from datasheets, not measured)
| Item | Wi-Fi mode | 4G-only |
|---|---|---|
| Deep sleep (1 mA target) | 0.09 Wh | 0.09 Wh |
| Armed check-ins (96/day Wi-Fi, 24/day 4G) | 0.16 | 0.17 |
| 50 events/day | 0.12 | 0.38 |
| Light + sensors | 0.04 | 0.04 |
| Losses ~15% | 0.06 | 0.10 |
| **Total** | **~0.5 Wh/day** | **~0.8 Wh/day** |

Requirement: <= 1.5 Wh/day. Panel yield estimate ~3 Wh/day good light, ~1.7 Wh/day Hanoi winter. Autonomy with no sun: ~14 days at 0.8 Wh/day (calculated, before reserve). Risk called out: a board with 5 mA sleep current adds ~0.4 Wh/day, so **measure first on the real board**.

## Layered tamper detection (hardware side)
| Layer | Sensor | Catches | Weakness (hence the next layer) |
|---|---|---|---|
| 1 | Accelerometer interrupt | lift, knock, tilt | pure left-right turn invisible |
| 2 | Compass (change from baseline) | turning | metal and wires disturb |
| 3 | Reed switch + magnet | cover opened / plate removed | strong external magnet defeats it |
| 4 | Server image comparison | lens covered, view changed | needs a check-in |
| 5 | Missed check-ins | power cut, jammed network | slow (minutes) |
Camera also reports accelerometer/reed wake **immediately** via `/device/v1/tamper` instead of waiting for the next check-in.

## Enclosure
- Wedge box 125 × 90 × 79 mm (55 mm at front), panel in a pocket on a 15° slope, hidden wall screws, cover slides on a back plate with 3 M3 screws (heat-set inserts).
- 3 parts: cover, back plate, lens hood. ASA, 0.2 mm layers, 4 perimeters, 30% infill. PLA unsuitable (heat).
- **Generated by code**: `hardware/enclosure/build_enclosure.py` (manifold3d + trimesh) builds the STL files from one parameter block. Change a number, rebuild.
- Status: Rev B, not printed. Rev C to model: magnet pocket, reed holder, reset-button access (using it while armed counts as tamper), seal groove, real-part dimensions.
- Thermal: closed box in Vietnamese sun can exceed 60 °C; light colour, shade by panel, vent plug option, charging stops above 45 °C by design.
- Goal IPX4 (splash). **No rating claimed**; proven only by hose test.

## 3D product model (generated from code)
`3d-model/build_product_model.py` (manifold3d + trimesh) builds the whole product as one glTF (`solavis-camera.glb`) with 26 named parts and PBR materials: rounded ASA shell (5 mm radius, 3.5 mm walls, 6.5 mm top), back plate with tongue ring and screw shelves, 110 × 80 mm panel in a 3.2 mm pocket on the 15° slope (alu frame, 5 × 3 cells, busbars), sealed 20 mm glass window, stacked lens (metal ring, black ring, blue-coated element, gold coating ring), tapered sun hood, AM312 Fresnel dome with ridges, LED with steel bezel, gold sun inlay, vent plug, then internals: dev board on four posts, ESP32 shield, LTE module, camera module, 18650 with caps, flexible antenna, reed capsule and magnet. Same dimensions as the print model, so one parameter block drives both. `solavis-camera.manifest.json` lists parts, groups and exploded-view offsets. Internal part shapes are simplified; real board dimensions are still to be confirmed. See `assets/3d/` for renders.

## Provisioning and test plan (designed)
- Provisioning script: flash firmware, create device ID + key, register in inventory with claim code, print QR label.
- End-of-line test (10 steps): battery read within 50 mV, sleep current, PIR wake, accelerometer wake, reed wake, sharp frame at 1.5 m, LED current <= 250 mA, upload over Wi-Fi and 4G, charge from lamp, claim by QR.
- Verification plan: 7-day outdoor power log, 7-day no-sun autonomy, heat log, charge cutoff at 0 and 45 °C, hose test, tilt at 5/8/15/30°, turn at 10/15/30°, lift-and-carry, slow/fast cover removal, covered lens, 2-week false-alarm count (wind, bird, truck), magnet bypass, Wi-Fi to 4G failover.

## Firmware contract (what the firmware must do; server already implements its side)
Claim with code -> store device key in protected storage -> wake on PIR/accel/reed/15-min timer -> heartbeat with battery, net, rssi, tilt, heading, cover, fw, tiny gray frame -> obey `state` and `upload` from config -> on face: upload crop with idempotency key -> on tamper wake: POST /tamper immediately -> never unlock itself (lock state in flash and on server).
